Анализ прототипа
Где ломается
обычный сценарий
Вывод анализа

Пользователь не хочет «вести систему». Он хочет быстро сбросить мысль.

TaskFlow строится вокруг свободного ввода, а не вокруг длинных форм.

Формы тормозят

Каждое обязательное поле повышает шанс, что задачу не внесут.

Голос быстрее

Пользователь уже привык отправлять голосовые сообщения в Telegram.

AI берёт рутину

Название, дедлайн, приоритет и группа извлекаются автоматически.

Напоминания рядом

Уведомления приходят туда же, где пользователь уже общается.

Анализ проблем
Три ключевых барьера
01

Потеря контекста

Задача появляется в одном чате, дедлайн — в другом, а итоговый план нигде не собирается.

02

Барьер ввода

Когда нужно заполнять форму, пользователь откладывает задачу «на потом».

03

Слепая зона голоса

Голосовые заметки нельзя нормально искать, фильтровать и превращать в очередь.
